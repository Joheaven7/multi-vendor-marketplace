# Multi-Vendor E-Commerce Marketplace

A production-style multi-vendor marketplace: customers buy from many sellers in one checkout,
and each seller manages only their own products, orders and earnings.

**Stack:** Next.js, TypeScript, Tailwind, Express, MongoDB, JWT.

## Structure

- `backend/` Express + TypeScript API
- `frontend/` Next.js app
- `docs/` project rules, MVP scope, business rules, phases

## Run locally

See `backend/.env.example` and `frontend/.env.example`.

    cd backend && npm install && npm run dev
    cd frontend && npm install && npm run dev

Full documentation is added in the final phase.
